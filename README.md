# MBS Shop

เกมจำลองร้านขายอาหารสไตล์ Pixel Art สำหรับกิจกรรม Open House
เล่นบนเว็บเบราว์เซอร์ รองรับ iPhone / iPad (แตะหน้าจอ) และเมาส์ ภาษาไทยทั้งเกม

## วิธีเล่น
- ลูกค้าเข้าร้านพร้อมใบออร์เดอร์ → แตะสถานีทำอาหาร (ไอศกรีม / แพนเค้ก / พิซซ่า) → ทำตามสูตร
- ถืออาหารแล้วแตะที่ลูกค้าที่สั่งเมนูนั้นเพื่อเสิร์ฟ (ส่งผิดคนจะไม่เสียของและไม่เสียคะแนน)
- สะสมให้ครบ 1,000 คะแนนก่อนหมดเวลา (เลือกเวลาได้ 2 / 3 / 5 นาที)
- หมุนจอเป็นแนวนอนเมื่อเล่นบนมือถือ

## เปิดเล่น
- เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ไม่ต้องมี Backend, API Key, Node.js หรือ npm)
- ภาพทั้งหมดฝังอยู่ในไฟล์ (base64) จึงเล่นแบบออฟไลน์ได้

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่ใน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้
2. ไปที่ **Settings → Pages**
3. หัวข้อ **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## โครงสร้าง
```
index.html   เกมทั้งหมด (HTML + CSS + JavaScript + ภาพที่ฝังไว้)
README.md    ไฟล์นี้
```
